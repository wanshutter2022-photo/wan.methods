ダイヤル操作
フルオートからの第一歩 ── 露出の3要素を覚えよう
★★★初級〜中級
🌱 前田さんへ・フルオート卒業の第一歩
まずは Av（絞り優先）モード から始めましょう
いきなり全部自分で決めるMモードは難しいので、まずは Av（絞り優先）モード から。F値（背景のボケ感）だけ自分で決めて、明るさはカメラが自動で調整してくれます。失敗しにくく、確実にステップアップできます🌸
📖 Canon用語のおさらい
SonyとはモードダイヤルNo名称が違います
P：プログラムオート　Av：絞り優先（SonyのA相当）　Tv：シャッタースピード優先（SonyのS相当）　M：マニュアル　A+：シーン自動判別（フルオート）
Av
モードダイヤル（カメラ上面）
撮影モードを「Av」にセット
カメラ上面の モードダイヤル を回して Av（絞り優先） に合わせます。F値だけ自分で決めて、シャッタースピードはカメラ任せ。慣れたら Tv（シャッター優先） や M（マニュアル） へステップアップ。
F
電子ダイヤル（カメラ上面・人差し指側）
絞り（F値）を変える
カメラ上面の 電子ダイヤル を人差し指で回してF値を変更します。F値が小さいほど（F2.8 など）背景がぼけて主役が際立ちます。

・F2.8〜F4：わんちゃんアップ（背景ボケ）
・F5.6〜F8：日常スナップ・複数頭撮影
・F11〜F16：全体をクッキリ（風景など）
±
コントロールホイール上ボタン（±マーク）
明るさを調整する（露出補正）
Avモード時、写真が明るすぎる・暗すぎる時は 露出補正 で調整。コントロールホイールの 上ボタン（±マーク） を押してから、電子ダイヤルを回して「＋」「－」方向に動かします。
ISO
前面のISOボタン または Q → ISO
ISOを設定する
カメラ前面・シャッターボタン後ろにある ISO感度設定ボタン を押すとISO設定画面が開きます。または Qボタン からも変更可能。初心者の方は ISO Auto がおすすめ。

・屋外昼間：ISO 100〜400
・室内・薄暗い：ISO 800〜3200
・夜間：ISO 3200〜6400
💡 前田さんへ・撮影設定の目安
  • 屋外・昼間：Avモード・F4〜F5.6・ISO Auto
  • 室内・薄暗い：Avモード・F2.8〜F4・ISO Auto
  • 動き回るわんちゃん：Tvモード・SS 1/500以上・ISO Auto
  • Canon EOS R50はISO3200まで余裕、ISO6400も実用範囲です
連写モード
動き回るわんちゃんを連続撮影で逃さない
★★★初級
1
コントロールホイール右ボタン（⏱マーク）
ドライブモードを開く
コントロールホイールの 右ボタン（⏱マーク） を押すと、ドライブモード選択画面が開きます。または MENU → カメラ設定 → ドライブモード からも設定可能。
2
コントロールホイールで選択
「高速連続撮影」を選ぶ
コントロールホイールで 「高速連続撮影」 を選択。Canon EOS R50 は最大 約15コマ／秒（電子シャッター） または 約12コマ／秒（メカニカルシャッター） の連写ができます。
3
シャッターボタン
シャッターを押し続ける
シャッターを 押し続けている間、連続して撮影されます。動き回るわんちゃんの決定的な瞬間をまとめて記録できます。
💡 連写のポイント
  • SDカードは UHS-II または UHS-I V30 以上推奨
  • 連写しすぎるとバッファが詰まることも。少しずつ連写するのがコツ
  • 撮った後に「一番いい1枚を選ぶ」練習もしてみましょう
  • 初心者は「低速連続撮影」（数コマ/秒）から始めるのもおすすめです
ピントの合わせ方
わんちゃんの「目」にピントを合わせるのが鉄則です
★★★中級
📖 Canon の AF モード
ワンショットAF と サーボAF を使い分ける
Canonでは 「ワンショットAF」（止まったもの） と 「サーボAF」（動くもの） で使い分けます。SonyではAF-S・AF-Cと呼ばれるものに相当します。Canon EOS R50 には 動物検出AF も搭載されており、わんちゃんの目を自動検出してくれます🐾
S
ワンショットAF
止まっているとき ── ワンショットAF
シャッター半押しでピントを合わせて 固定 します。寝ているわんちゃん・ポーズを決めた瞬間など 動かない被写体 に最適。合うと「ピピッ」と音が鳴ります。
C
サーボAF
動いているとき ── サーボAF
半押し中、動く被写体を 追いかけてピントを合わせ続けます。走り回るわんちゃんには 必ずこれ を使いましょう。Canon EOS R50 のサーボAFは初心者にも扱いやすい性能です。
切替
Q ボタン → AFモード
AFモードの切り替え方
Q ボタン を押してクイック設定画面を表示し、AFモードを選択 → ワンショット／AIフォーカス／サーボ から選びます。または MENU → AF → AFモード からも設定可能。
👁
MENU → AF → 検出する被写体
動物検出AFを必ずONに ⭐
MENU → AF → 検出する被写体 → 「動物優先」 を選択。これでわんちゃんの目を自動検出してピントを合わせてくれます✨ サーボAF と組み合わせれば、走り回る子もばっちり追従します。
💡 ピント設定のポイント
  • 動物検出AFは「動物優先」モードで人物・動物両方を認識可能
  • 動くわんちゃんは「サーボAF + 動物検出」が最強の組み合わせ
  • 液晶を直接タップしてピント位置を指定することもできます
  • 動物検出AFが効かない時はわんちゃんの顔が小さすぎる可能性。少し近づいてみて
AFエリア
「どこにピントを合わせるか」の範囲を決める設定
★★★中級
開く
Q ボタン → AFエリア
Q ボタンから開く
Q ボタン を押してクイック設定画面を表示。AFエリアを選んでコントロールホイールで変更します。または、AFフレーム選択ボタン（⊕マーク）からも変更できます。
W
全域AF ── まず試すならコレ
全域AF
画面全体でカメラが 自動的に被写体を選んでピント を合わせます。動物検出AFと組み合わせれば、初心者の方でも失敗が少ないです。

前田さんはまずこの「全域AF」＋ 動物検出AF で始めるのがおすすめ✨
Z
ゾーンAF
ゾーンAF
画面内の特定のエリアを優先してピントを合わせます。わんちゃんがいる位置が予測できる ときに便利です。
●
1点AF / スポット1点AF
1点AF ✏ 修正済み
タッチパネルで ピントを合わせたい場所を直接タップ して指定できます。また、コントロールホイールの上下左右ボタン（十字キー） でもピント位置を移動できます。

※ EOS R50にはジョイスティック（マルチコントローラー）はありません。タッチパネルが最も素早く使えます。

「手前のお花にピントが行ってしまう」あるあるは、1点AFに切り替えれば解決します。
💡 前田さんへ・AFエリアのステップアップ
  • STEP 1：まず「全域AF + 動物検出AF」で撮ってみましょう
  • STEP 2：慣れてきたら「ゾーンAF」で構図を意識して撮影
  • STEP 3：お花畑や障害物のあるシーンでは「1点AF」で確実に目を狙う
  • ピント位置の移動は液晶を直接タップするのが一番速いです
画面表示
グリッド線とヒストグラムで「構図」と「明るさ」を見える化
★★★初級〜中級
⊞ グリッド線 ── 三分割法で構図を決める
1
MENU ボタン
MENU ボタンを押す
背面右下の MENU ボタン を押してメニュー画面を表示します。
2
SET UP → グリッド表示
グリッド表示を選ぶ
「SET UP」タブ → 「グリッド表示」 を選択し、グリッドの種類を選びます。
3
種類を選ぶ
「3×3」を選ぶ
「3×3」 を選択します。画面が9つに分割され、線の交点が 被写体を置くとキレイに見える位置（三分割法のポイント）になります。
三分割法 ── 黄色の交点に被写体の目を合わせると◎
💡 構図のポイント
  • 目は必ず交点（黄色のポイント）の近くに配置しましょう
  • わんちゃんの進行方向に「空間」を作ると動きが伝わりやすくなります
  • グリッドは写真には写りません ── 常に表示したままで大丈夫です
📊 ヒストグラム ── 写真の明るさを「グラフ」で確認
📖 ヒストグラムとは？
写真の明るさを可視化するグラフ
液晶の見た目だけでは分からない「正確な明るさ」をグラフで確認できる機能です。横軸 = 暗い ← → 明るい、縦軸 = そのトーンのピクセル数 で表示されます。
1
INFO ボタン
INFO ボタンで表示切替
背面の INFO ボタン を何度か押すと、ヒストグラムが表示される画面に切り替わります。
2
再生画面 → INFO ボタン
撮影後にも確認できる
撮影した写真でも、再生画面で INFO ボタン を押すとヒストグラムを確認できます。「あれ、ちょっと暗かったかな？」という時に客観的に確認できます。
⚠
山が左に偏る
暗い・黒つぶれ注意
露出補正＋に
✓
山が中央〜やや右
適正露出
理想的なバランス
⚠
山が右に偏る
白飛び注意
露出補正－に
白い毛色のわんちゃん
山はやや右寄りが正解
右端で切れない範囲で右に寄せる。露出補正は ＋0.7〜＋1.0。
黒い毛色のわんちゃん
山は左寄りでも問題なし
左端ギリギリで止まるくらいの露出に。露出補正は －0.7〜－1.0。
茶色系・混色のわんちゃん
中央付近が目安
最も適正露出を判断しやすい。両端で切れない範囲で露出を決める。
💡 ヒストグラム実践のコツ
  • 逆光シーン：背景の白飛びを許容して、わんちゃんの顔の露出を優先
  • 雪・砂浜・白い壁：山が右に寄りすぎないよう露出補正－0.7〜－1.0
  • 液晶で見て大丈夫そうより ヒストグラムを信じる のが鉄則です
親指AF設定
AEロックボタンをカスタムしてプロの撮り方に近づこう
★★★上級
📖 親指AFとは？
シャッターとAFを「分離」する撮り方
通常はシャッター半押しでAFが動きますが、親指AFでは AF用ボタンだけでAFを動かし、シャッターはAFなしで切れるようにします。Canon EOS R50 には専用のAF-ONボタンがないので、AEロックボタン（✱マーク）をカスタマイズして親指AFを実現します。
1
MENU → カスタム機能(C.Fn) → ボタンカスタマイズ
MENU からカスタム機能を開く
MENU → 「カスタム機能（C.Fn）」タブ → 「ボタンカスタマイズ」 を選択。
2
AEロックボタン → 「測距・AF開始」を割り当て
AEロックボタンに「AFオン」を割り当て
一覧から 「AEロックボタン」 を選択し、「測距・AF開始」 を割り当てます。これで AEロックボタンが親指AF用ボタンに変身します。
3
同じ画面 → シャッターボタン → 「AE/FEロック」
シャッター半押しのAFを切る
同じ画面で 「シャッターボタン」 を 「AE/FEロック」 に変更。これでシャッターはAFなしで切れるようになります。
4
右親指で AEロック（✱）を押しながら撮影
実際の使い方
右手親指で AEロックボタン（✱マーク）を押している間だけAFが動きます。ピントが合ったらボタンを離してシャッターを切ります。
通常AF と 親指AF の違い
通常AF（初期設定）
シャッター半押し → AF動く
シャッター全押し → 撮影

✔ 操作がシンプル
△ ピント固定が難しい
親指AF（カスタム後）
AEロックを押す → AF動く
シャッター → AFなしで撮影

✔ ピント固定が自在
✔ 動体・静止体の切替が速い
💡 親指AF のポイント
  • 前田さんはまず通常のAFに慣れてから、次のステップとして挑戦するのがおすすめです
  • Canon EOS R50 はAF-ON専用ボタンがないので、AEロックボタンを活用します
  • 元に戻したい場合は「ボタンカスタマイズ」をリセットするだけです

ダイヤル操作
マニュアル撮影の基本 ── 露出の3要素を覚えよう
★★★中級
M
モードダイヤル(カメラ上面)
撮影モードを選ぶ
カメラ上面のダイヤルを回して撮影モードを選びます。A(絞り優先)ならボケ感重視の撮影、M(マニュアル)なら全部自分で決める撮影。α6700には 静止画/動画/S&Q 切換ダイヤル もあるので、必ず 静止画モード になっていることも確認してください。
SS
後ダイヤル(親指側)
シャッタースピードを変える
背面右上の 後ダイヤル を親指で回します。動きを止めるには 1/500 以上 が目安。ペット・子どもには 1/1000〜1/2000 がおすすめです。
F
コントロールホイール(背面)
絞り(F値)を変える
背面右側の コントロールホイール を回します。F値が小さいほど(F1.8 など)背景がぼけて主役が際立ちます。
※α6700はα7C IIと違い 前ダイヤルがありません。Aモードではホイールで絞り、Mモードでは後ダイヤル(SS)＋ホイール(F値)の組み合わせになります。
ISO
Fn ボタン → ISO
ISOを設定する
Fn ボタン を押してファンクションメニューを開き、ISO を選択します。室内・暗い場所では ISO 800〜3200 を目安に調整しましょう。
💡 撮影設定の目安
  • 屋外・昼間：SS 1/1000・F2.8〜4・ISO AUTO
  • 室内・薄暗い：SS 1/500・F1.8〜2.8・ISO 1600〜3200
  • APS-Cセンサーは高感度耐性ではフルサイズに少し劣るため、ISOは抑えめが理想です
連写モード
最高約11コマ/秒の高速連写でペットを逃さない
★★★初級
1
コントロールホイール左ボタン
ドライブモードを開く
コントロールホイールの 左ボタン(ドライブモード) を押します。画面にモード選択肢が表示されます。MENU → 撮影 → ドライブモードからも設定可能です。
2
コントロールホイールで選択
「連続撮影：Hi+」を選ぶ
コントロールホイールを回して 連続撮影 Hi+(最高速) を選択。α6700 は最大 約11コマ／秒 の連写ができ、α7C IIより高速です。
3
シャッターボタン
シャッターを押し続ける
シャッターを 押し続けている間、連続して撮影されます。圧縮RAW＋高速SDなら数百枚連写してもバッファが詰まりにくく、決定的瞬間を逃しません。
💡 連写のポイント
  • SDカードは UHS-II または UHS-I V30 以上推奨
  • ロスレス圧縮RAWは連写速度が下がるので、連写重視の場面は圧縮RAWまたはJPEGで
  • Hi+使用時はEVFの表示が「撮影中の画像」になります(ブラックアウトはなし)
ピントの合わせ方
AIプロセッシングユニット搭載の強力なAFを使いこなそう
★★★中級
S
AF-S(シングルAF)
止まっているとき ── AF-S
シャッター半押しでピントを合わせて 固定 します。寝ているわんちゃん・ポーズを決めた瞬間など 動かない被写体 に最適。
C
AF-C(コンティニュアスAF)
動いているとき ── AF-C
半押し中、動く被写体を 追いかけてピントを合わせ続けます。走り回るわんちゃんには 必ずこれ。AIプロセッシングユニットのおかげで、追従精度は歴代APS-Cで最高クラスです。
切替
MENU → フォーカス → AF/MF → フォーカスモード
AFモードの切り替え方
MENUの 「フォーカス」タブ から 「AF/MF」 → 「フォーカスモード」 で切り替えます。Fn メニューに割り当てておくのが最速です。
👁
MENU → フォーカス → 被写体認識
AI被写体認識で動物・鳥AFを使う
α6700の AIプロセッシングユニット は専用設計の認識AIで、人物・動物・鳥・昆虫・車などを判別します。「被写体認識」を「動物」に設定すれば、犬・猫の 目・顔・体を高精度で検出。AF-Cと組み合わせれば、走り回る子もばっちり追従します。
💡 ピント設定のポイント
  • AI被写体認識は「動物」と「鳥」を独立して認識可能。撮影シーンに応じて切り替えを
  • AF被写体追従感度を「1(粘る)〜5(敏感)」で調整可能。雑踏では「粘る」が有効
  • 慣れている方は「親指AF」(AF-ON)との組み合わせで自由度MAXに
フォーカスエリア
「どこにピントを合わせるか」の範囲を決める設定
★★★中級
開く
Fn ボタン → フォーカスエリア
Fn ボタンから開く
Fn ボタン を押してファンクションメニューを表示。フォーカスエリアを選んでコントロールホイールで変更します。
W
ワイド ── 被写体認識との相性◎
ワイド
画面全体でカメラが 自動的に被写体を選んでピント を合わせます。AI被写体認識と組み合わせれば、画面内のわんちゃんを自動で捕捉します。
Z
ゾーン
ゾーン
画面内の特定のエリアを優先してピントを合わせます。ペットがいる位置が予測できる ときに便利です。
●
フレキシブルスポット
スポット
タッチパネルで ピントを合わせたい場所を直接タップ できます。コントロールホイールの上下左右ボタンでもピント位置の移動が可能。目だけにピントを合わせたいときに最も使います。
💡 フォーカスエリアのポイント
  • タッチパネル対応なので、画面を直接タップしてピント位置を指定できます
  • 「フォーカスエリア限定」設定で、使うエリアだけに絞ると切替がスピーディに
  • APS-Cの利点で同じ画角でも望遠寄りに撮れるので、スポット+望遠で目を狙うのが効果的
画面表示
グリッド線とヒストグラムで「構図」と「明るさ」を見える化
★★★初級〜中級

⊞ グリッド線 ── 三分割法で構図を決める

1
MENU ボタン
MENU ボタンを押す
背面上部の MENU ボタン を押してメニュー画面を表示します。
2
撮影 → 撮影画面表示 → グリッドライン表示
グリッドライン表示を選ぶ
「撮影」タブ → 「撮影画面表示」 → 「グリッドライン表示」 を「入」にします。次に「グリッドラインの種類」で形式を選択します。
3
種類を選ぶ
「3分割」を選ぶ
「3分割」 を選択します。画面が9つに分割され、線の交点が 被写体を置くとキレイに見える位置(三分割法のポイント)になります。
三分割法 ── 黄色の交点に被写体の目を合わせると◎
💡 構図のポイント
  • 目は必ず交点(黄色のポイント)の近くに配置しましょう
  • わんちゃんの進行方向に「空間」を作ると動きが伝わりやすくなります
  • APS-Cは望遠側に強いので、SEL70350Gなどの望遠で背景圧縮＋三分割法が映えます

📊 ヒストグラム ── 写真の明るさを「グラフ」で確認

📖 ヒストグラムとは？
写真の明るさを可視化するグラフ
液晶の見た目だけでは分からない「正確な明るさ」をグラフで確認できる機能です。屋外の明るい場所や暗い場所で「液晶で見ると明るいけど実は暗かった」という失敗を防げます。横軸 = 暗い ← → 明るい、縦軸 = そのトーンのピクセル数(山の高さ)で表示されます。
1
DISP ボタン(コントロールホイール上)
DISP ボタンで表示切替
コントロールホイールの 上ボタン(DISP) を何度か押すと、画面表示が切り替わります。「ヒストグラム」表示に切り替えてください。
2
MENU → セットアップ → 表示オプション → DISP(画面表示)設定
DISP切替で表示する内容を選ぶ
DISPボタンを押した時に表示される画面パターンをカスタマイズできます。「ヒストグラム」のチェックを入れておきましょう。
ヒストグラムの読み方 ── 山の位置で明るさが分かる
📚 基本編：読み方のキホン
  • 横軸の見方：左端=真っ黒、右端=真っ白、中央=中間グレー
  • 山が右端で途切れている → 白飛び(明るい部分のディテール消失)
  • 山が左端で途切れている → 黒つぶれ(暗い部分のディテール消失)
  • 理想の形：山が左右に偏らず、なだらかに分布している状態
  • 液晶の見た目より ヒストグラムを信じる のが鉄則です
🎯 実践編：ペット撮影でのヒストグラム活用
わんちゃんの毛色で読み方を変える
わんちゃんの体色によって、理想のヒストグラムは変わります。同じ「適正露出」でも、白い子と黒い子では山の位置が違って当然なのです。
白
白い毛色のわんちゃん
山はやや右寄りが正解
マルチーズ・サモエド・白柴など 白い毛色の子 を撮るときは、山が右寄りになるのが自然。右端で切れない範囲で、できるだけ右に寄せるのがコツ。これを「ETTR(Expose To The Right)」と呼びます。白い毛の質感やフワフワ感がしっかり残せます。
黒
黒い毛色のわんちゃん
山は左寄りでも問題なし
黒柴・黒ラブ・トイプーの黒など 黒い毛色の子 は、山が左寄りになるのが自然。ただし左端で切れると毛のディテールが消えるので、左端ギリギリで止まるくらいの露出に。露出補正ーで山が左端まで行かないよう調整します。
混
白＋黒の混色 / 茶色系
山が左右に分かれる(山が2つできる)
パピヨン・チワワ(白×茶)など色が混ざった子は、ヒストグラムに 2つの山 ができることがあります。両方の山が端で切れない範囲で露出を決めましょう。茶色系は中央付近に山が来やすいので、最も適正露出を判断しやすい色です。
💡 ヒストグラム実践のコツ
  • 逆光シーン：背景の白飛びを許容して、わんちゃんの顔の露出を優先
  • 雪・砂浜・白い壁：山が右に寄りすぎないよう露出補正−0.7〜−1.0
  • 森の中・夜景：山が左に寄りすぎないよう露出補正+0.3〜+0.7
  • α6700は RGBヒストグラム表示 も可能(MENU→セットアップ→表示オプション)。赤・緑・青の各色チャンネルで飽和(白飛び)していないか確認できます
  • ゼブラ表示(白飛び部分が縞模様で点滅)も併用すると、撮影中に白飛びをリアルタイムで把握できます
  • α7C IIと操作系がほぼ同じなので、両機種で同じワークフローが使えます
親指AF設定
AF-ON ボタンをカスタムしてプロの撮り方に近づこう
★★★上級
📖 親指AFとは？
シャッターとAFを「分離」する撮り方
通常はシャッター半押しでAFが動きますが、親指AFでは AF-ON ボタンだけでAFを動かし、シャッターはAFなしで切れるようにします。動く被写体と止まった被写体を素早く切り替えられる、プロも愛用する撮り方です。α6700はAF-ONボタンを正面に搭載しているので、親指AFを使いやすい機種です。
1
MENU → セットアップ → 操作カスタマイズ → カスタムキー/ダイヤル設定
MENU からカスタムキー設定を開く
MENU → 「セットアップ」タブ → 「操作カスタマイズ」 → 「カスタムキー／ダイヤル設定」 を選択。
2
AF-ON ボタンの割り当てを確認
AF-ON ボタンは「AFオン」のまま
一覧から 「AF-ON ボタン」 を確認します。初期設定の 「AFオン」 のままでOK。変更は不要です。
3
MENU → フォーカス → AF/MF → シャッター半押しAF
シャッター半押しのAFを「切」にする
「フォーカス」タブ → 「AF/MF」 → 「シャッター半押しAF」 を 「切」 に変更します。これでシャッターはAFなしで切れるようになります。
4
右親指で AF-ON を押しながら撮影
実際の使い方
右手親指で AF-ON ボタンを押している間だけAFが動きます。ピントが合ったらボタンを離してシャッターを切ります。ピントを固定したまま構図を変えられるのが最大の利点です。
通常AF と 親指AF の違い
通常AF(初期設定)
シャッター半押し → AF動く
シャッター全押し → 撮影

✔ 操作がシンプル
△ ピント固定が難しい
親指AF(カスタム後)
AF-ON を押す → AF動く
シャッター → AFなしで撮影

✔ ピント固定が自在
✔ 動体・静止体の切替が速い
💡 親指AF のポイント
  • α7C IIと操作系がほぼ同じなので、両機種で同じワークフローが使えます
  • 「ピントが外れやすい」と感じている方に特に効果的
  • α6700はAF-ONに「押す間トラッキング+AFオン」を割り当てると、押すだけで追従AFが起動します
  • 元に戻したい場合は「シャッター半押しAF」を「入」に戻すだけです

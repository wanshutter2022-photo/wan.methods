ダイヤル操作
iPhoneから一歩進んで ── 露出を自分でコントロールしよう
★★★初級〜中級
🌱 武笠さんへ・iPhone卒業の第一歩
まずは A（絞り優先）モード から始めましょう
iPhoneは全自動ですが、α6400は A（絞り優先）モード から始めるのがおすすめ。F値（背景のボケ感）だけ自分で決めて、シャッタースピードはカメラ任せ。ピノナノちゃんが花畑に佇む写真のような ふわっとした背景ボケ はF値を下げることで生まれます🌸
A
モードダイヤル（上面右）
撮影モードを「A」にセット
上面右のモードダイヤルを回して A（絞り優先） に合わせます。まずはこのモードに慣れましょう。動きを止めたいときは S（シャッター優先）、全部自分で決めるなら M（マニュアル） へ。
F
コントロールホイール回転（背面右）
絞り（F値）を変える
背面右の コントロールホイール を回してF値を変更。

・F2.8〜F4：ピノナノちゃんのアップ（背景ボケ）
・F5.6〜F8：2頭一緒にクッキリ撮る
・F11〜：花畑全体と一緒に撮る
SS
S モード時：コントロールホイール回転
シャッタースピードを変える（S モード）
走り回るピノナノちゃんを撮るときは S（シャッター優先） モードに変更。1/500〜1/1000 以上に設定すると動きをピタッと止められます。
ISO
コントロールホイール右ボタン（ISO）
ISOを設定する
コントロールホイールの 右ボタン（ISO） を押してISO設定画面を開きます。または Fn ボタン からも変更可能。

・屋外：ISO Auto または ISO 100〜400
・室内：ISO 800〜3200
・夜間：ISO 3200〜6400
💡 ピノナノちゃん撮影の設定目安
  • 花畑・公園（晴天）：Aモード・F2.8〜4・ISO Auto → 花がボケて2頭が際立つ
  • 室内・薄暗い場所：Aモード・F2.8・ISO 1600〜3200
  • 走り回るとき：Sモード・SS 1/1000・ISO Auto
  • 2頭並んで撮るとき：F5.6〜8で両方ピントが合いやすくなります
連写モード
ピノナノちゃんの決定的瞬間を逃さない
★★★初級
1
コントロールホイール 左ボタン（⏱ドライブ）
ドライブモードを開く
コントロールホイールの 左ボタン（ドライブモード） を押します。または Fn ボタン → ドライブモードからも設定可能です。
2
コントロールホイールで選択
「連続撮影：Hi」を選ぶ
ホイールを回して 連続撮影 Hi（高速） を選択。α6400 は最大 約11コマ／秒 の連写が可能です。ピノナノちゃんが動き回るシーンで大活躍します。
3
シャッターボタン
シャッターを押し続ける
シャッターを 押し続けている間 連続撮影されます。ピノナノちゃんが2頭揃って同じ方向を向いた瞬間を狙いましょう✨
💡 連写のポイント
  • SDカードは UHS-I V30 以上推奨（書き込みが速いほど連写が続きます）
  • 2頭撮りは「どちらかの目にピントが合っている瞬間」を後で選ぶ楽しさがあります
  • 撮った後に「一番いい1枚を選ぶ」のも立派な写真の技術です
ピントの合わせ方
ピノナノちゃんの「目」にピントを合わせるのが鉄則🐾
★★★中級
S
AF-S（シングルAF）
止まっているとき ── AF-S
シャッター半押しでピントを合わせて 固定 します。花畑でじっとしているピノナノちゃんなど 動かない被写体 に最適。合うと「ピピッ」と音が鳴ります。
C
AF-C（コンティニュアスAF）
動いているとき ── AF-C
半押し中、動く被写体を 追いかけてピントを合わせ続けます。走り回るピノナノちゃんには 必ずこれ を使いましょう。
切替
Fn ボタン → フォーカスモード
AFモードの切り替え方
Fn ボタン を押してファンクションメニューを表示し、フォーカスモードを選択。AF-S・AF-A・AF-C・MF から選びます。または AF/MF ダイヤル（上面）からも切り替え可能です。
👁
MENU → フォーカス → 被写体認識AF
動物AF・瞳AFを使う ⭐
α6400 には リアルタイム瞳AF（動物対応） が搭載されています。MENU → フォーカス → 被写体認識AF → 「動物」 を選択。AF-C と組み合わせれば、ピノナノちゃんの目を自動追従します✨ iPhoneにはできない撮り方です。
💡 ピント設定のポイント
  • 動物瞳AFは「動物」設定でピノナノちゃんの目を自動検出
  • 2頭撮りのとき：手前の子の目にピントを合わせると自然なボケが生まれます
  • AF-C ＋ 動物瞳AF ＋ 連写の組み合わせが最強です
  • 液晶タッチでピントを合わせたい目を直接タップすることもできます
フォーカスエリア
「どこにピントを合わせるか」の範囲を決める設定
★★★中級
開く
Fn ボタン → フォーカスエリア
Fn ボタンから開く
Fn ボタン を押してファンクションメニューを表示。フォーカスエリアを選んでコントロールホイールで変更します。
W
ワイド ── まず試すならコレ
ワイド
画面全体でカメラが 自動的に被写体を選んでピント を合わせます。動物瞳AFと組み合わせれば、ピノナノちゃんの目を自動で捕捉します。最初はワイドからスタート✨
Z
ゾーン
ゾーン
画面内の特定エリアを優先してピントを合わせます。2頭のうち 特定の子にピントを合わせたい ときに便利です。
●
フレキシブルスポット
スポット（1点）
タッチパネルで ピントを合わせたい場所を直接タップ できます。ピノナノちゃんそれぞれの目に確実にピントを合わせたいときに最も精度が高い方法です。
💡 2頭撮りのフォーカスエリア活用法
  • 2頭が並んでいる → ワイド＋動物瞳AFでどちらかの目を自動検出
  • どちらか1頭だけ撮りたい → スポットでその子の目をタップ
  • 動き回っている → ゾーンで大まかなエリアを指定して追従
グリッド線
三分割法で構図が決まる！格子線をモニターに表示しよう
★★★初級
1
MENU ボタン
MENU ボタンを押す
上面の MENU ボタン を押してメニュー画面を表示します。
2
撮影 → 撮影画面表示 → グリッドライン表示 → 入
グリッドライン表示を「入」にする
「撮影」タブ → 「撮影画面表示」 → 「グリッドライン表示」 を「入」にして、種類を「3分割」に設定します。
3
交点を意識して構図を決める
「3分割」を選んで構図を決める
線の 交点（4カ所） にピノナノちゃんの目を置くと自然に美しい構図になります。2頭を横に並べるときは 左右の交点 を意識してみましょう。
三分割法 ── 2頭並んで撮るときの構図イメージ
💡 構図のポイント
  • 2頭を左右の交点に配置すると自然にバランスが取れます
  • どちらか1頭だけ撮るときは、進行方向の前に空間を作ると動きが出ます
  • 花畑撮影では手前の花をぼかして奥のピノナノちゃんにピントを合わせると奥行きが出ます
親指AF設定
AELボタンをカスタムしてプロの撮り方に近づこう
★★★上級
📖 親指AFとは？
シャッターとAFを「分離」する撮り方
通常はシャッター半押しでAFが動きますが、親指AFでは AELボタンだけでAFを動かし、シャッターはAFなしで切れるようにします。ピノナノちゃんにピントを合わせたまま構図を自由に変えられるのが最大の利点です。
1
MENU → セットアップ → 操作カスタマイズ → カスタムキー設定
カスタムキー設定を開く
MENU → 「セットアップ」タブ → 「操作カスタマイズ」 → 「カスタムキー設定」 を選択します。
2
AELボタン → 「AFオン」を割り当て
AELボタンに「AFオン」を割り当て
一覧から 「AELボタン」 を選択し、「AFオン」 を割り当てます。
3
MENU → フォーカス → AF/MF → シャッター半押しAF → 切
シャッター半押しのAFを「切」にする
「シャッター半押しAF」 を 「切」 に変更します。これでシャッターはAFなしで切れるようになります。
4
右親指でAELを押しながら撮影
実際の使い方
右手親指で AELボタンを押している間だけAFが動きます。ピノナノちゃんにピントを合わせたらボタンを離してシャッターを切ります。構図だけ自由に動かせるのが最大の利点です。
通常AF と 親指AF の違い
通常AF（初期設定）
シャッター半押し → AF動く
シャッター全押し → 撮影

✔ 操作がシンプル
△ ピント固定が難しい
親指AF（カスタム後）
AELを押す → AF動く
シャッター → AFなしで撮影

✔ ピント固定が自在
✔ 2頭撮りでの切り替えが速い
💡 親指AF のポイント
  • まず通常のAFに慣れてから挑戦するのがおすすめです
  • 2頭撮りで「どちらかの子にピント固定 → 構図を変えてもう1頭も入れる」という技が使えます
  • 元に戻したい場合は「シャッター半押しAF」を「入」に戻すだけです

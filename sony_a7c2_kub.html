ダイヤル操作
マニュアル撮影の基本 ── 露出の3要素を覚えよう
★★★中級
M
モードダイヤル(カメラ上面)
撮影モードを選ぶ
カメラ上面の モードダイヤル を回して撮影モードを選びます。初心者には A(絞り優先) から始めるのがおすすめ。F値だけ自分で決めて、明るさはカメラ任せにできます。慣れたら M(マニュアル) へ。
SS
後ダイヤル(右上)
シャッタースピードを変える
α7C IIには 前ダイヤル・後ダイヤル・コントロールホイール の3つがあり、Mモードでは 後ダイヤル でSSを調整します。動きを止めるには 1/500 以上、ペットには 1/1000〜1/2000 がおすすめ。
F
前ダイヤル(上部)
絞り(F値)を変える
液晶モニターの上にある 前ダイヤル を回します。F値が小さいほど(F1.8など)背景がぼけて主役が際立ちます。Aモードでは前ダイヤル単独で絞りを変更できます。
ISO
コントロールホイール右ボタン
ISOを設定する
コントロールホイールの右ボタン(ISO)を押すと、すぐにISO設定画面が開きます。または Fn ボタンからも変更可能。室内・暗い場所では ISO 800〜3200 を目安に調整しましょう。
💡 撮影設定の目安
  • 屋外・昼間：SS 1/1000・F2.8〜4・ISO AUTO
  • 室内・薄暗い：SS 1/500・F1.8〜2.8・ISO 1600〜3200
  • α7C IIはフルサイズで高感度に強いので、ISO 6400まで実用範囲です
連写モード
動き回るペット・子どもを連続撮影で逃さない
★★★初級
1
コントロールホイール左ボタン
ドライブモードを開く
コントロールホイールの 左ボタン(ドライブモード) を押します。画面にモード選択肢が表示されます。MENU → 撮影 → ドライブモードからも設定可能。
2
コントロールホイールで選択
「連続撮影：Hi+」を選ぶ
コントロールホイールを回して 連続撮影 Hi+(最高速) を選択。α7C II は最大 約10コマ／秒 の連写ができます。
3
シャッターボタン
シャッターを押し続ける
シャッターを 押し続けている間、連続して撮影されます。決定的な瞬間の前後をまとめて記録できます。
💡 連写のポイント
  • SDカードは UHS-II または UHS-I V30 以上推奨
  • Hi+ より Hi のほうが枚数が抑えられ、後から選びやすい
  • 撮った後に「一番いい1枚を選ぶ」練習もしてみましょう
ピントの合わせ方
AFモードを使い分けて、止まったコ・動くコを撮り分けよう
★★★中級
S
AF-S(シングルAF)
止まっているとき ── AF-S
シャッター半押しでピントを合わせて 固定 します。寝ているわんちゃん・ポーズを決めた瞬間など 動かない被写体 に最適。合うと「ピピッ」と音が鳴ります。
C
AF-C(コンティニュアスAF)
動いているとき ── AF-C
半押し中、動く被写体を 追いかけてピントを合わせ続けます。走り回るわんちゃんには 必ずこれ。α7C IIはAIプロセッシングユニット搭載で、追従精度が非常に高いです。
切替
MENU → フォーカス → AF/MF → フォーカスモード
AFモードの切り替え方
MENUの 「フォーカス」タブ から 「AF/MF」 → 「フォーカスモード」 で切り替えます。Fn メニューに割り当てておくのが最速です。
👁
MENU → フォーカス → 被写体認識
AI被写体認識で動物AFを使う
α7C IIの AIプロセッシングユニット は人物・動物・鳥・昆虫・車などを高精度で認識します。「被写体認識」を「動物」に設定すれば、犬・猫の 目・顔・体を高精度で検出。AF-C と組み合わせれば、走り回る子もばっちり追従します。
💡 ピント設定のポイント
  • AI被写体認識は「動物」と「鳥」を独立して認識可能
  • α7C IIはフルサイズなのでボケが大きく、目に確実にピントを合わせることが重要
  • 慣れている方は「親指AF」(AF-ON)との組み合わせで自由度MAXに
フォーカスエリア
「どこにピントを合わせるか」の範囲を決める設定
★★★中級
開く
Fn ボタン → フォーカスエリア
Fn ボタンから開く
Fn ボタン を押してファンクションメニューを表示。フォーカスエリアを選んでコントロールホイールで変更します。
W
ワイド ── 被写体認識との相性◎
ワイド
画面全体でカメラが 自動的に被写体を選んでピント を合わせます。AI被写体認識と組み合わせれば、画面内のわんちゃんを自動で捕捉します。
Z
ゾーン
ゾーン
画面内の特定のエリアを優先してピントを合わせます。ペットがいる位置が予測できる ときに便利です。
●
フレキシブルスポット
スポット
タッチパネルで ピントを合わせたい場所を直接タップ できます。コントロールホイールの上下左右ボタンでもピント位置の移動が可能。目だけにピントを合わせたいときに最も使います。
💡 フォーカスエリアのポイント
  • タッチパネル対応なので、画面を直接タップしてピント位置を指定できます
  • 「フォーカスエリア限定」設定で、使うエリアだけに絞ると切替がスピーディに
  • フルサイズの広いボケを活かすには、スポットで目を正確に狙うのが効果的
画面表示
グリッド線とヒストグラムで「構図」と「明るさ」を見える化
★★★初級〜中級

⊞ グリッド線 ── 三分割法で構図を決める

1
MENU ボタン
MENU ボタンを押す
上部の MENU ボタン を押してメニュー画面を表示します。
2
撮影 → 撮影画面表示 → グリッドライン表示
グリッドライン表示を選ぶ
「撮影」タブ → 「撮影画面表示」 → 「グリッドライン表示」 を「入」にします。次に「グリッドラインの種類」で形式を選択します。
3
種類を選ぶ
「3分割」を選ぶ
「3分割」 を選択します。画面が9つに分割され、線の交点が 被写体を置くとキレイに見える位置(三分割法のポイント)になります。
三分割法 ── 黄色の交点に被写体の目を合わせると◎
💡 構図のポイント
  • 目は必ず交点(黄色のポイント)の近くに配置しましょう
  • わんちゃんの進行方向に「空間」を作ると動きが伝わりやすくなります
  • フルサイズ＋単焦点なら背景圧縮＋三分割法で作品感のある写真に

📊 ヒストグラム ── 写真の明るさを「グラフ」で確認

📖 ヒストグラムとは？
写真の明るさを可視化するグラフ
液晶の見た目だけでは分からない「正確な明るさ」をグラフで確認できる機能です。屋外の明るい場所や暗い場所で「液晶で見ると明るいけど実は暗かった」という失敗を防げます。横軸 = 暗い ← → 明るい、縦軸 = そのトーンのピクセル数(山の高さ)で表示されます。
1
DISP ボタン(コントロールホイール上)
DISP ボタンで表示切替
コントロールホイールの 上ボタン(DISP) を何度か押すと、画面表示が切り替わります。「ヒストグラム」表示に切り替えてください。
2
MENU → セットアップ → 表示オプション → DISP(画面表示)設定
DISP切替で表示する内容を選ぶ
DISPボタンを押した時に表示される画面パターンをカスタマイズできます。「ヒストグラム」のチェックを入れておきましょう。
ヒストグラムの読み方 ── 山の位置で明るさが分かる
📚 基本編：読み方のキホン
  • 横軸の見方：左端=真っ黒、右端=真っ白、中央=中間グレー
  • 山が右端で途切れている → 白飛び(明るい部分のディテール消失)
  • 山が左端で途切れている → 黒つぶれ(暗い部分のディテール消失)
  • 理想の形：山が左右に偏らず、なだらかに分布している状態
  • 液晶の見た目より ヒストグラムを信じる のが鉄則です
🎯 実践編：ペット撮影でのヒストグラム活用
わんちゃんの毛色で読み方を変える
わんちゃんの体色によって、理想のヒストグラムは変わります。同じ「適正露出」でも、白い子と黒い子では山の位置が違って当然なのです。
白
白い毛色のわんちゃん
山はやや右寄りが正解
マルチーズ・サモエド・白柴など 白い毛色の子 を撮るときは、山が右寄りになるのが自然。右端で切れない範囲で、できるだけ右に寄せるのがコツ。これを「ETTR(Expose To The Right)」と呼びます。白い毛の質感やフワフワ感がしっかり残せます。
黒
黒い毛色のわんちゃん
山は左寄りでも問題なし
黒柴・黒ラブ・トイプーの黒など 黒い毛色の子 は、山が左寄りになるのが自然。ただし左端で切れると毛のディテールが消えるので、左端ギリギリで止まるくらいの露出に。露出補正ーで山が左端まで行かないよう調整します。
混
白＋黒の混色 / 茶色系
山が左右に分かれる(山が2つできる)
パピヨン・チワワ(白×茶)など色が混ざった子は、ヒストグラムに 2つの山 ができることがあります。両方の山が端で切れない範囲で露出を決めましょう。茶色系は中央付近に山が来やすいので、最も適正露出を判断しやすい色です。
💡 ヒストグラム実践のコツ
  • 逆光シーン：背景の白飛びを許容して、わんちゃんの顔の露出を優先
  • 雪・砂浜・白い壁：山が右に寄りすぎないよう露出補正−0.7〜−1.0
  • 森の中・夜景：山が左に寄りすぎないよう露出補正+0.3〜+0.7
  • α7C II は RGBヒストグラム表示 も可能(MENU→セットアップ→表示オプション)。赤・緑・青の各色チャンネルで飽和(白飛び)していないか確認できます
  • ゼブラ表示(白飛び部分が縞模様で点滅)も併用すると、撮影中に白飛びをリアルタイムで把握できます
親指AF設定
AF-ON ボタンをカスタムしてプロの撮り方に近づこう
★★★上級
📖 親指AFとは？
シャッターとAFを「分離」する撮り方
通常はシャッター半押しでAFが動きますが、親指AFでは AF-ON ボタンだけでAFを動かし、シャッターはAFなしで切れるようにします。動く被写体と止まった被写体を素早く切り替えられる、プロも愛用する撮り方です。
1
MENU → セットアップ → 操作カスタマイズ → カスタムキー/ダイヤル設定
MENU からカスタムキー設定を開く
MENU → 「セットアップ」タブ → 「操作カスタマイズ」 → 「カスタムキー／ダイヤル設定」 を選択。
2
AF-ON ボタンの割り当てを確認
AF-ON ボタンは「AFオン」のまま
一覧から 「AF-ON ボタン」 を確認します。初期設定の 「AFオン」 のままでOK。変更は不要です。
3
MENU → フォーカス → AF/MF → シャッター半押しAF
シャッター半押しのAFを「切」にする
「フォーカス」タブ → 「AF/MF」 → 「シャッター半押しAF」 を 「切」 に変更します。これでシャッターはAFなしで切れるようになります。
4
右親指で AF-ON を押しながら撮影
実際の使い方
右手親指で AF-ON ボタンを押している間だけAFが動きます。ピントが合ったらボタンを離してシャッターを切ります。ピントを固定したまま構図を変えられるのが最大の利点です。
通常AF と 親指AF の違い
通常AF(初期設定)
シャッター半押し → AF動く
シャッター全押し → 撮影

✔ 操作がシンプル
△ ピント固定が難しい
親指AF(カスタム後)
AF-ON を押す → AF動く
シャッター → AFなしで撮影

✔ ピント固定が自在
✔ 動体・静止体の切替が速い
💡 親指AF のポイント
  • シャッター半押しAFに慣れてから次のステップとして挑戦しましょう
  • 「ピントが外れやすい」と感じている方に特に効果的
  • AF-ONに「押す間トラッキング+AFオン」を割り当てると、押すだけで追従AFが起動
  • 元に戻したい場合は「シャッター半押しAF」を「入」に戻すだけです
